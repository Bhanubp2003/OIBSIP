# Task 2: Unemployment Analysis with Python

## Internship
Oasis Infobyte Data Science Internship

## Project Objective
The objective of this project is to analyze unemployment trends in India using Python. The project focuses on understanding unemployment rate, estimated employment, labour participation rate, regional differences, and Covid-19 period changes.

## Dataset Used
Two datasets were used:
1. Unemployment in India.csv
2. Unemployment_Rate_upto_11_2020.csv

The main analysis was performed using the updated unemployment dataset up to November 2020.

## Tools and Libraries Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Steps Performed
1. Imported required Python libraries
2. Loaded the unemployment datasets
3. Cleaned column names
4. Checked and removed missing values
5. Converted the date column into datetime format
6. Created month and year columns
7. Analyzed average unemployment rate
8. Compared unemployment rate across regions
9. Analyzed unemployment by zone
10. Visualized unemployment trends during 2020
11. Created correlation heatmap
12. Generated insights and conclusion

## Key Insights
- Unemployment rates differed across regions in India.
- Some regions recorded higher unemployment rates than others.
- The unemployment rate increased during the Covid-19 period.
- Zone-wise analysis helped compare unemployment patterns geographically.
- Labour participation and employment levels varied across regions.

## Conclusion
This project helped analyze real-world unemployment data using Python. The visualizations provided clear insights into unemployment trends, regional differences, and Covid-19 impact on employment in India.
