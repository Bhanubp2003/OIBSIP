# Task 2: Unemployment Analysis with Python

## Internship
Oasis Infobyte Data Science Internship

## Project Objective
This project performs exploratory data analysis on unemployment data in India. The main objective is to understand regional and temporal unemployment trends, with a special focus on the impact of the COVID-19 pandemic.

## Dataset
The project uses unemployment datasets containing information such as:
- Region
- Date
- Estimated Unemployment Rate
- Estimated Employed
- Estimated Labour Participation Rate
- Area / Zone

## Tools and Technologies Used
- Python
- Jupyter Notebook
- pandas
- matplotlib
- seaborn

## Project Workflow
1. Loaded the unemployment datasets
2. Inspected dataset shape, columns, data types, and missing values
3. Cleaned column names and handled missing values
4. Converted the Date column into datetime format
5. Performed region-wise unemployment analysis
6. Analyzed month-wise unemployment trends
7. Compared unemployment trends for selected major states
8. Identified top 10 states with highest average unemployment rate
9. Created a correlation heatmap
10. Compared Pre-COVID and During/Post-COVID unemployment rates

## Key Visualizations
- Region-wise average unemployment rate
- Month-wise unemployment trend
- Time-series line chart for selected states
- Top 10 states with highest unemployment rate
- Correlation heatmap
- Pre-COVID vs During/Post-COVID comparison

## Key Insights
- Unemployment rates varied significantly across regions in India.
- Some states showed consistently higher average unemployment rates.
- The unemployment rate increased strongly during the COVID-19 period.
- Labour participation and estimated employment differed across regions.
- Visual analysis helped identify temporal and regional unemployment patterns.

## Conclusion
This project helped analyze real-world unemployment data using Python. Through data cleaning, exploratory analysis, and visualization, the project shows how unemployment changed across Indian regions and how COVID-19 affected unemployment trends.
