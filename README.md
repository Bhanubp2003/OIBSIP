# Completed Tasks

## Task 1: Iris Flower Classification

### Objective

The objective of this task is to build a machine learning model that can classify iris flowers into different species based on their measurements.

### Dataset Used

The dataset contains flower measurements such as:

* Sepal length
* Sepal width
* Petal length
* Petal width
* Species

### Model Used

* Random Forest Classifier

### Result

The model successfully classified iris flowers into the correct species with very good accuracy.

### Task Folder

(./Task-1_Iris_Flower_Classification)

---

## Task 2: Unemployment Analysis with Python

### Objective

The objective of this task is to analyze unemployment data in India and understand unemployment trends across different regions and time periods.

### Dataset Used

Two unemployment datasets were used:

* Unemployment in India
* Unemployment Rate up to November 2020

### Key Work Done

* Data cleaning
* Exploratory data analysis
* State-wise unemployment analysis
* Region-wise comparison
* Visualization of unemployment trends

### Result

The analysis helped identify unemployment patterns across different states and regions in India.

### Task Folder

(./Task-2_Unemployment_Analysis)

## Task 3: Car Price Prediction

### Objective

The objective of this task is to predict the selling price of a car based on features such as present price, fuel type, transmission type, seller type, and car age.

### Dataset Used

The dataset contains details such as:

* Car name
* Year
* Selling price
* Present price
* Kilometers driven
* Fuel type
* Seller type
* Transmission
* Owner details

### Model Used

A machine learning regression model was used to predict car prices.

### Result

The model was able to predict car selling prices based on important input features.

### Task Folder

(./Task-3_Car_Price_Prediction)

## Task 4: Email Spam Detection

### Objective

The objective of this task is to build a machine learning model that can classify messages as spam or not spam.

### Dataset Used

The dataset contains SMS/email text messages labelled as:

* Spam
* Ham / Not Spam

### Key Work Done

* Text preprocessing
* Label encoding
* Feature extraction using text vectorization
* Model training
* Spam prediction

### Result

The model successfully classified messages as spam or not spam.

### Task Folder

(./Task-4_Email_Spam_Detection)

## Task 5: Sales Prediction Using Python

### Objective

The objective of this task is to predict sales based on advertising budgets spent on TV, Radio, and Newspaper.

### Dataset Used

The dataset contains advertising spending details:
